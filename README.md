# 📋 کپی مسیر فولدر برنامه از روی PID

این اسکریپت پایتون به شما این امکان رو می‌ده که با وارد کردن **PID** (شماره شناسۀ پردازش یک برنامه)، مسیر فولدری که فایل اجرایی اون برنامه در اون قرار داره رو **کپی کنید به کلیپ‌بورد**.

## 🛠 کتابخانه‌های مورد استفاده

- [`psutil`](https://pypi.org/project/psutil/): برای دریافت اطلاعات مربوط به پردازش‌ها و مسیر فایل اجرایی.
- [`os`](https://docs.python.org/3/library/os.html): برای کار با مسیرها و فایل‌ها.
- [`pyperclip`](https://pypi.org/project/pyperclip/): برای کپی کردن اطلاعات به کلیپ‌بورد سیستم.

## 🔄 نحوه عملکرد

1. از کاربر یک عدد به‌عنوان PID دریافت می‌شود.
2. با استفاده از `psutil`، مسیر فایل اجرایی برنامه با آن PID استخراج می‌شود.
3. مسیر فولدر فایل اجرایی (نه خود فایل) با استفاده از `os.path.dirname` جدا می‌شود.
4. مسیر فولدر در کلیپ‌بورد ذخیره می‌شود.
5. در صورت وقوع خطا، پیام مناسب به کاربر نمایش داده می‌شود.
